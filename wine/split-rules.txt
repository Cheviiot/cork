# Что из собранного Wine едет пользователю, а что остаётся у нас.
#
# Читается tools/wine/split-devel.sh. Формат: «класс образец», по одному на
# строку; путь сверяется относительно корня дерева, побеждает первое
# совпадение. Пустые строки и строки с # игнорируются.
#
#   runtime — уезжает пользователю
#   sdk     — отдельный артефакт: нужен только нам, чтобы собрать PE-хелпер
#   drop    — не нужно никому
#
# Зачем список, а не «выбросить include и *.a». Затем, что **файл, не
# подошедший ни под один образец, останавливает сборку**. Без этого состав
# артефакта определяется тем, что `make install` положил сегодня, и всякая
# правка в дереве Wine молча меняет то, что уезжает пользователю. Сейчас
# devel попадает в артефакт именно так — побочным эффектом, нигде не
# закреплённым, — и любая будущая оптимизация размера так же молча его
# снесёт. Список превращает состав в решение, а не в следствие.
#
# Правило для новой строки: сначала убедиться, что без файла работает
# приёмочная матрица, и только потом переводить его из runtime.

# --- инструменты разработки -------------------------------------------------
# Всё это нужно, только чтобы собрать PE-хелпер, а собирается он в CI и едет
# вшитым в бинарник cork. На машине пользователя winegcc не зовётся ни разу.
sdk bin/winegcc
sdk bin/wineg++
sdk bin/winecpp
sdk bin/winebuild
sdk bin/winemaker
sdk bin/widl
sdk bin/wmc
sdk bin/wrc
sdk bin/winedump
sdk bin/function_grep.pl

# Заголовки Windows и libc++ из дерева Wine: 70 МБ, нужны только компилятору
# хелпера.
sdk include/**

# Импорт-библиотеки: и PE, и ELF-овые. 77 МБ, нужны только компоновщику
# хелпера.
sdk lib/wine/*/*.a
sdk lib/wine/*/*.def

# Справочные страницы наших же инструментов разработки.
sdk share/man/**

# --- рантайм ----------------------------------------------------------------
runtime bin/wine
runtime bin/wineserver
runtime bin/wineboot
runtime bin/winepath
runtime bin/msiexec
runtime bin/msidb
runtime bin/regsvr32
runtime bin/regedit
runtime bin/winecfg
runtime bin/wineconsole
runtime bin/winedbg
runtime bin/winefile
runtime bin/notepad
runtime bin/winemine

runtime lib/wine/**
runtime share/wine/**
runtime share/applications/**
